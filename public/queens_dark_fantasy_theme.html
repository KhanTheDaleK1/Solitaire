1. Suit-Specific Elemental Lighting

Each Queen features dedicated color keying: Hearts uses deep crimson & ruby staff light; Spades emits arcane lilac & violet haze; Diamonds reflects warm topaz & amber fire; Clubs channels emerald woodland glows.

2. Unbroken Metallic Outer Edge

Using a padding: 3.5px trick on the parent .card-gilded element creates a clean, beveled gold border that will never allow character vector artwork to bleed onto table felts.

3. Performance Optimization for Mobile

For instant 60 FPS mobile drag physics, pre-render court portraits as single WebP/AVIF assets with transparent or pre-baked vignettes, rather than drawing complex real-time SVG paths per frame.
